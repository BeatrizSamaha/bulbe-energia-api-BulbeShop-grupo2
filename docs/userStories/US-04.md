## User Story

**Como** frontend da aplicação,
**quero** adicionar um produto ao carrinho do usuário,
**para** persistir os itens selecionados e redirecionar para a tela de carrinho.

---

## Critérios de Aceitação

- [ ] O endpoint responde com status 201 ao adicionar item
- [ ] A resposta retorna o carrinho atualizado
- [ ] Se o produto já existir no carrinho, incrementa a quantidade

---

## Requisito Funcional Vinculado

**RF-04:** O sistema deve permitir adicionar produtos ao carrinho do usuário autenticado.

---

## Endpoint Esperado

| Verbo | Path | Autenticação |
|-------|------|--------------|
| POST | /api/v1/carrinho/itens | JWT |
