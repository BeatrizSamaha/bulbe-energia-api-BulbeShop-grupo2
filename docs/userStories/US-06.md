## User Story

**Como** frontend da aplicação,
**quero** remover um item específico do carrinho,
**para** atualizar o carrinho quando o usuário excluir um produto ou zerar a quantidade.

---

## Critérios de Aceitação

- [ ] O endpoint responde com status 204 ao remover com sucesso
- [ ] Responde 404 se o item não existir no carrinho
- [ ] O item é completamente removido do carrinho

---

## Requisito Funcional Vinculado

**RF-06:** O sistema deve permitir remover itens do carrinho do usuário autenticado.

---

## Endpoint Esperado

| Verbo | Path | Autenticação |
|-------|------|--------------|
| DELETE | /api/v1/carrinho/itens/:id | JWT |
