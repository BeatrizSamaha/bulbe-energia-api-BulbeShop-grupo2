## User Story

**Como** frontend da aplicação,
**quero** criar um pedido a partir dos itens do carrinho,
**para** iniciar o fluxo de pagamento com endereço e método de pagamento.

---

## Critérios de Aceitação

- [ ] O endpoint responde com status 201 ao criar o pedido
- [ ] A resposta retorna o id do pedido criado
- [ ] Responde 422 se o carrinho estiver vazio

---

## Requisito Funcional Vinculado

**RF-10:** O sistema deve criar um pedido a partir dos itens do carrinho do usuário.
