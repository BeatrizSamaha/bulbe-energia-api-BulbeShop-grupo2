## User Story

**Como** frontend da aplicação,
**quero** buscar os itens do carrinho do usuário,
**para** exibir a tela de carrinho com produtos, quantidades e total.

---

## Critérios de Aceitação

- [ ] O endpoint responde com status 200
- [ ] Retorna array de itens com id, title, price, qty, img
- [ ] Retorna array vazio se o carrinho estiver vazio

---

## Requisito Funcional Vinculado
