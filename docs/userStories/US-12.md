## User Story

**Como** frontend da aplicação,
**quero** processar o pagamento de um pedido via boleto,
**para** exibir o código de barras na tela de boleto.

---

## Critérios de Aceitação

- [ ] O endpoint responde com status 200 e retorna o código de barras
- [ ] Responde 404 se o pedido não existir
- [ ] Responde 422 se o pedido já estiver pago

---

## Requisito Funcional Vinculado

**RF-12:** O sistema deve processar pagamentos via boleto retornando o código de barras.

---

## Endpoint Esperado

| Verbo | Path | Autenticação |
|-------|------|--------------|
| POST | /api/v1/pedidos/:id/pagamento/boleto | JWT |
