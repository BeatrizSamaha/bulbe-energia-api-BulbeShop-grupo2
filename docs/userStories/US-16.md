## User Story

**Como** frontend da aplicação,
**quero** buscar os cupons de desconto disponíveis para o usuário,
**para** exibir a tela de cupons com os descontos disponíveis.

---

## Critérios de Aceitação

- [ ] O endpoint responde com status 200
