## User Story

**Como** usuário autenticado,
**quero** visualizar e editar meus dados de perfil (nome, CPF, telefone, senha),
**para** manter minhas informações atualizadas na tela de Meu Perfil.

---

## Critérios de Aceitação

- [ ] GET responde com status 200 e retorna os dados do usuário
- [ ] PUT responde com status 200 ao atualizar com sucesso
- [ ] Responde 422 se os dados forem inválidos (ex: CPF mal formatado)

---

## Requisito Funcional Vinculado

**RF-14:** O sistema deve permitir visualizar e editar os dados do perfil do usuário autenticado.

---

## Endpoint Esperado

| Verbo | Path | Autenticação |
|-------|------|--------------|
| GET | /api/v1/usuarios/perfil | JWT |
| PUT | /api/v1/usuarios/perfil | JWT |
